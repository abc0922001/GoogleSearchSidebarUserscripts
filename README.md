# Google 搜尋「工具」選單側邊欄攤開腳本 (Google Search Tools Sidebar)

將 Google 搜尋結果頁面頂部需要點擊「工具（Tools）」才能看到的下拉選單（語言、時間範圍、結果模式、進階搜尋等），直接**垂直攤開並內嵌於搜尋結果左側空白處**，復刻早期 Google 搜尋一目了然的直向側邊欄體驗。

本專案為**極簡、零外部相依性**的開放原始碼使用者腳本（Userscript），完全相容於 **ScriptCat（腳本貓）**、**Tampermonkey** 與 **Violentmonkey** 等主流瀏覽器擴充功能。

---

## 功能特色

- **直向攤開、一鍵篩選**：直接於頁面左側展示所有篩選子項目，無須反覆點擊頂部「工具」按鈕或展開多層下拉選單。
- **雙引擎保底架構（DOM 提取 + 網址參數備援）**：
  - **優先提取原生選單**：自動解析 Google 原生 `#hdtbMenus` / `g-menu` 選單項目；針對「自訂日期範圍...」等互動項目採用**代理點擊（Proxy Click）**技術，100% 保留 Google 原生日期選擇對話框行為。
  - **網址參數動態保底**：若遇 Google A/B 測試改版導致原生選單未預先載入，自動以 `URLSearchParams` 動態組合標準篩選連結，確保側邊欄永遠穩定可用，並支援多維度條件疊加（例如同時套用「過去 24 小時」與「完全符合」）。
- **零侵入絕對定位排版**：
  - 僅在「全部」與「網頁（`udm=14`）」搜尋分頁顯示，自動避開圖片、影片、新聞、購物等特殊分頁。
  - 絕不修改 Google 原生主內容欄位的寬度與邊距；當視窗寬度不足（`< 1250px`）或左側留白空間不夠時自動隱藏，絕不遮擋搜尋結果。
- **深淺色主題自適應**：自動偵測 Google 頁面背景明度與系統深色模式，動態切換文字、分隔線、懸停背景與啟用狀態（`✓`）強調色。
- **純淨輕量**：單一檔案、零外部函式庫、無自訂設定面板或浮動按鈕、無任何追蹤程式碼。

## 支援的篩選項目

側邊欄由上而下垂直排列以下篩選群組（群組間以細水平線分隔）：

1. **語言與地區篩選**
   - 不限語言
   - 繁體中文網頁（`lr=lang_zh-TW`）
   - 台灣的網頁（`cr=countryTW`）
   *(若 Google 原生選單根據您的介面語言提供其他項目，將自動同步呈現)*
2. **時間範圍篩選**
   - 不限時間
   - 過去 1 小時（`tbs=qdr:h`）
   - 過去 24 小時（`tbs=qdr:d`）
   - 過去 1 週（`tbs=qdr:w`）
   - 過去 1 個月（`tbs=qdr:m`）
   - 過去 1 年（`tbs=qdr:y`）
   - 自訂日期範圍...（觸發 Google 原生日期範圍對話框）
3. **結果比對模式**
   - 所有結果
   - 完全符合（`tbs=li:1`）
4. **附加工具**
   - 清除篩選（僅於目前已套用任一篩選條件時顯示）
   - 進階搜尋（跳轉至 Google 原生進階搜尋頁面並保留當前查詢關鍵字）

## 安裝方式

### 步驟 1：安裝腳本管理器擴充功能

請先在您的瀏覽器（Chrome、Edge 或 Firefox）安裝任一支援 Userscript 的瀏覽器擴充功能：

- **ScriptCat（腳本貓）**（推薦）
- **Tampermonkey**
- **Violentmonkey（暴力猴）**

### 步驟 2：安裝本腳本

- **GitHub 一鍵直接安裝**：[**👉 點此直接安裝腳本 (GoogleSearchSidebar.user.js)**](https://github.com/abc0922001/GoogleSearchSidebarUserscripts/raw/main/GoogleSearchSidebar.user.js)（點擊後腳本管理器會自動彈出安裝確認視窗）。
- **從 Greasy Fork 安裝**：前往本腳本的 Greasy Fork 頁面，點擊「安裝此腳本」即可完成。
- **手動安裝**：開啟腳本管理器的「新增腳本」介面，將本專案中的 `GoogleSearchSidebar.user.js` 完整內容貼上並儲存。

安裝完成後，前往 [Google 台灣搜尋](https://www.google.com.tw/search?q=test&hl=zh-TW) 或 [Google 國際搜尋](https://www.google.com/search?q=test&hl=zh-TW)（視窗寬度建議 `1250px` 以上），即可在搜尋結果左側看見攤開的工具側邊欄。
